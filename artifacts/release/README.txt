FM26 Player Editor
==================

바로 실행:
  FM26-Player-Editor.exe
  FM26-Player-Editor-MVP.exe

설치해서 사용:
  FM26-Player-Editor-Setup.exe

권장 실행 방식:
  Football Manager 26을 켠 뒤, 이 프로그램을 관리자 권한으로 실행하세요.
  fm.exe 메모리 읽기/쓰기는 일반 권한에서 실패할 수 있습니다.

현재 상태:
  UID로 선수 검색
  검색한 선수 이름 표시
  최근 검색/즐겨찾기 저장
  공개 능력치/포지션/선호 플레이 읽기
  숨김 수치는 값 보기를 눌렀을 때만 읽기
  UID 목록 기반 스카우팅 센터
  클럽/팀 ID로 선수 UID 자동 수집
  조사 단계별 PA/CA 구간 리포트
  변경 대기 후 모두 적용 또는 원래 값으로 되돌리기

스카우팅 MVP:
  스카우팅 탭에서 클럽/팀 ID와 스쿼드를 입력한 뒤 UID 불러오기를 누르세요.
  수집된 UID 목록은 직접 수정하거나 붙여넣을 수도 있습니다.
  조사 단계가 올라갈수록 PA/CA 구간이 더 촘촘하게 표시됩니다.

선수 얼굴:
  faces 폴더에 UID.png, UID.jpg, UID.jpeg, UID.webp 형식으로 넣으면 표시됩니다.
  예: faces\2002074288.png

주의:
  세이브 파일은 먼저 백업해두고 테스트하세요.
