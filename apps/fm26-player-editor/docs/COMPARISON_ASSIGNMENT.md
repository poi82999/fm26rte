# 선수 컴패리즌 배정표

작성일: 2026-05-07

이 문서는 스카우팅 리포트에서 유망주에게 붙는 "비교군"의 현재 배정 기준과 실제 우선 배정표를 정리한다.

## 적용 조건

- 컴패리즌은 `나이 24세 이하`이고 `PA 150 이상`인 선수에게만 붙는다.
- `PA 195 이상`은 별도 엘리트 아이콘 풀만 사용한다.
- `PA 170-194`도 별도 우선표 없이 기존 강점 기반 슬롯만 사용한다.
- `PA 150-179`는 세부 포지션 슬롯이 있으면 세부 슬롯을 먼저 사용하고, 없으면 광역 슬롯으로 폴백한다.
- 같은 슬롯 안에 유망주와 같은 국적의 비교군이 있으면 같은 국적 선수를 우선 배정한다.
- 같은 국적 선수가 없으면 `UID + PA + 포지션 + 강점` 기반 seed로 한 명을 고정 선택한다.

## PA 구간 철학

| PA 구간 | 의미 | 배정 밀도 |
|---|---|---|
| 195-200 | 축구 역사상 최상위 아이콘 | 극소수 |
| 190-194 | 발롱도르 수상자, 강력한 후보, 시대 상징급 | 희소 |
| 180-189 | 한 시대를 대표한 월드클래스/전설급 | 선별 |
| 170-179 | 매 시즌 정상급 활약을 한 스타급 | 상세 |
| 160-169 | 빅클럽 주전급 또는 전 세계 상위권 선수 | 보통 |
| 150-159 | 빅리그 상위권/빅클럽 로테이션급 | 넓게 |

## 현재 조정 메모

- 190-194는 억지로 3명씩 채우지 않고, 발롱도르급/역사급으로 납득되는 소수만 유지한다.
- 로드리는 6번 포지션의 현시대 교과서 위상을 반영해 190-194 미드필더 정신 슬롯에 배치했다.
- 사비 에르난데스, 안드레아 피를로, 프랑크 레이카르트, 하비에르 사네티, 티에리 앙리, 호나우두는 과거 레전드 표본 보강 차원에서 상위 PA 구간에 추가했다.
- 180-189는 세부 포지션보다 선수 위상 정합성이 중요하므로 광역 슬롯을 우선한다.
- 비니시우스 주니오르, 가브리엘 바티스투타, 앙투안 그리즈만은 180-189 공격수 슬롯에 배치했다. 비니시우스는 드리블/크랙 유형을 살리기 위해 기술 슬롯으로 조정했다.
- 170-179는 리포트 다양성을 위해 4231 기준 세부 포지션 슬롯을 유지한다.
- 주앙 칸셀루, 테오 에르난데스, 카일 워커, 빅터 오시멘, 트렌트 알렉산더-아놀드, 은골로 캉테, 마르틴 외데고르, 후벵 디아스, 필 포든은 170-179 세부 포지션 슬롯에 배치했다.
- 필리페 쿠티뉴와 에릭 다이어는 최근 위상/포지션 경향을 반영해 150-159로 조정했고, 다이어는 CenterBack 정신 슬롯으로 분리했다.
- 160-169와 150-159는 현재 광역 슬롯 중심이다. 이후 필요하면 세부 포지션 슬롯을 추가하되, PA 구간에 맞는 선수만 넣는다.
- 벤자민 멘디와 델레 알리는 현재 비교군에서 삭제했다.
- 현재 일반 비교군 안에서 중복 선수명은 없다.
